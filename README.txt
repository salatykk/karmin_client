KARMIN CLIENT — магазин и лаунчер приложений студии KARMIN
==========================================================

Готовый установщик: release\KarminClient-Setup-1.0.0.exe
Запустите его, выберите папку, и на рабочем столе появится ярлык «Karmin Client».
Установщик не подписан, поэтому Windows SmartScreen может показать
«Система Windows защитила ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае».

КАК ДОБАВИТЬ ПРИЛОЖЕНИЕ
1. Откройте файл src\apps.js в любом редакторе (например, VS Code или Блокнот).
2. Скопируйте блок приложения Quik и вставьте его ниже. Блоки разделяются запятой.
3. Укажите id, name, tagline, description, ссылку releases на GitHub
   (https://github.com/ВЛАДЕЛЕЦ/РЕПО/releases), recommended (true или false) и accent (цвет).
   Каждое поле подробно описано в комментариях в начале файла.
4. В каждом релизе на GitHub должен лежать установщик .exe без слова «portable»
   в имени, например «Quik-Setup-1.2.5.exe». Клиент сам берёт последний релиз,
   скачивает этот файл и запускает его.
5. Иконку приложения можно положить в renderer\assets\apps\ и указать в поле icon.

КАК ПЕРЕСОБРАТЬ УСТАНОВЩИК (Windows)
1. Один раз установите Node.js LTS: https://nodejs.org
2. Откройте PowerShell в папке KarminClient и выполните:
       npm install
       npm test            (проверка каталога и логики выбора установщика)
       npm start           (запуск клиента без сборки, для проверки)
       npm run dist        (сборка установщика)
3. Новый установщик появится в папке dist\KarminClient-Setup-<версия>.exe.
   Версию клиента меняйте в package.json, в поле "version".

ГДЕ ЧТО ЛЕЖИТ
  src\apps.js          каталог приложений (редактировать здесь)
  src\github.js        выбор релиза и установщика, сравнение версий
  main.js              скачивание, установка, запуск, окно
  renderer\            интерфейс (HTML, CSS, JS, шрифты, 3D-сцена scene.js)
  src\scene.module.js  исходник 3D-сцены; после правки выполните npm run scene
  build\icon.ico       иконка приложения

Данные клиента (установленные версии и пути к программам) хранятся в
%APPDATA%\Karmin Client\state.json.
